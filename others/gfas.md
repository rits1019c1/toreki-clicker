# GFAS 言語仕様書 / GFAS Language Specification

> **GFAS** — *Gɪnmɐ-Fɔrm Ɐrtɪfɪʃɐl Szɪstɛm*  
> 直訳：「疑念形式人工体系」  
> 実態：意味不明な架空言語。東暦クリッカーの第4言語。

---

## 1. 概要 / Overview

GFASは東暦クリッカーに搭載された架空言語である。  
英語・日本語・スラブ語系の音韻を「悪い翻訳機を3回通したような」形に意図的に崩したものがベースとなっている。

**特徴：**
- 語順が崩れている（動詞優先、主語省略が多い）
- 独自の母音変化（Ø, ɯ, ɐ, ɪ, ɛ など IPA 風文字を多用）
- 二重子音・子音クラスターが多い（`sz`, `kh`, `gn`, `vø`, `trekk`）
- 文末に句点なし、または `.` のみ
- 感情表現は記号の重複で表す（`!!`, `??`, `—`）
- 外来語はそのまま崩さず使う場合もある（`TXT`, `×1`, `I / II / III`）

## 2. 音韻体系 / Phonology

### 2-1. 母音 (Vowels)

| 表記 | 発音の目安 | 例 |
|------|------------|-----|
| `ɐ`  | 中央低母音（"uh" に近い） | `Tɪmɐ`, `Klɔzɐ` |
| `ɪ`  | 狭前舌母音（"i" より曖昧） | `Rɛvørtrekk`, `Bɪldɣnz` |
| `ɛ`  | 半広前舌母音（"e" と "æ" の間） | `Qvɛrztn`, `Bɪldɣnz` |
| `ɯ`  | 狭後舌非円唇母音（"u" の非円唇版） | `Rɛnchɯ`, `Mʊzyn` |
| `ø`  | 前舌円唇母音（ドイツ語の "ö"） | `Tøkirek`, `Nø` |
| `ʊ`  | 広めの "u" | `Mʊzyn`, `Ɣɪld` |
| `ɔ`  | 後舌半広円唇（"o" より広い） | `Klɔzɐ`, `Lɔdɐ` |

### 2-2. 子音クラスター (Consonant Clusters)

GFAS は英語にない子音の組み合わせを好む。

| クラスター | 目安の発音 | 例 |
|------------|-----------|-----|
| `sz`       | `s` + `z` を素早く（ポーランド語的） | `Qvɛrztn`, `Kɛɪp Gøɪŋ` |
| `kh`       | 摩擦音的 `k`（アラビア語的） | `Klɪkh`, `Tɪmqvɛn` |
| `qv`       | `q` + `v` を連続 | `Qvɛrztn`, `Qv/sz` |
| `vø`       | `v` + 円唇母音 | `Rɛvørtrekk` |
| `ɣn`       | 有声軟口蓋摩擦音 + `n` | `Bɪldɣnz`, `Lɐŋɣwɪdʒ` |
| `trekk`    | `tr` + `ekk`（強調語尾） | `Rɛvørtrekk` |
| `θ`        | 英語 "th"（無声） | `Nøθɪŋ`, `Ɛvrɪθɪŋ` |

## 3. 文法 / Grammar

### 3-1. 語順 (Word Order)

GFAS の基本語順は **VSO（動詞→主語→目的語）** または **VO（動詞→目的語）** で、主語省略が頻繁に起こる。

```
英語:  Someone keeps asking questions.
GFAS:  Szɯmwɐn kɛɪpz ɐskɪŋ qvɛrztns.
        (主語前置の例外 — 英語の影響が残っている場合)

英語:  Questions are born.
GFAS:  Qvɛrztn børnz.
        (主語省略・自動詞文)

英語:  Nothing is certain.
GFAS:  Nøθɪŋ sɛrtɛɪn.
        (be動詞省略)
```

### 3-2. 動詞変化 (Verb Conjugation)

GFASは動詞変化が**ほぼ存在しない**。時制は文脈または副詞で示す。

| 時制 | 副詞 | 例 |
|------|------|-----|
| 現在 | （なし / `nɔw`） | `Kɔnsɛpts gɛnɛrɛɪt qvɛrztns nɔw.` |
| 過去 | `wɐz`, `dɔn` | `Fɪrst Rɛvørtrekk dɔn.` |
| 未来 | `wɪl`, `søn` | （未使用）|

### 3-3. 否定 (Negation)

否定は `nø`（英語 "no" のø変形）を動詞・名詞の前に置く。

```
Nø bøtm.        （底はない）
Nøθɪŋ sɛrtɛɪn. （確かなものは何もない）
Nøn rɛtrɯn.    （誰も戻らない）
Nøbɔdɪ ɐskɪŋ.  （誰も問うていない）
```

### 3-4. 疑問文 (Questions)

文末に `?` を置くだけ。語順変化なし。

```
Rɛvørtrekk nɔw?    （転生する？）
Bøtm?              （底は？）
Rɛɐlɪ dɪlɛt ɛvrɪθɪŋ??  （本当に全部消す？？）
```

疑問符の重複（`??`）は強調・驚きを表す。

### 3-5. 修飾語 (Modifiers)

修飾語は被修飾語の**後ろ**に置く（名詞後置修飾）。

```
Kjɯrɪøsɪ = Curiosity（単体）
Dɛpɐ Kjɯrɪøsɪ = Deeper Curiosity（Dɛpɐ が後ろから修飾…例外的に前置も可）
```

> ⚠️ GFASの修飾語順は不安定。話者（ゲームシステム）が気分で変える。これは意図的な設計。

## 5. 文体的ルール / Style Rules

1. **be動詞は省略する**  
   `Nøθɪŋ sɛrtɛɪn.`（Nothing [is] certain.）

2. **文は短く切る**  
   長文より短文の羅列を好む。`Bøtm? Nø bøtm.`

3. **主語は省略されがち**  
   `Qvɛrztns ɐsk qvɛrztns.`（[They are] questions asking questions.）

4. **感情は記号で示す**  
   - 驚き・強調 → `!!` または `??`
   - 沈黙・省略 → `—`
   - 疑問 → `?`（語順変化なし）

5. **外来語は保持する**  
   数字（`1,000`）、記号（`×2`）、省略語（`TXT`）はそのまま使う。

6. **冗長な表現を嫌う**  
   `Szɛvd.` で「保存されました」を表す。修飾語より事実のみ。

7. **文末ピリオドは任意**  
   正式な通知には `.` をつける。カジュアルな表現にはつけないことも。

## 6. 造語ルール / Word Formation Rules

新しいGFAS語を作る際のガイドライン：

```
元の英語単語 → GFAS化
---
1. 母音を近い IPA 文字に置換
   a → ɐ / e → ɛ / i → ɪ / o → ɔ / u → ɯ または ʊ

2. 特定の子音を強調クラスターに
   s → sz（語中・語末）
   k → kh（語末または強調）
   ng → ɣn または ŋ

3. 名詞語尾 -tion → -tɪŋ または -ɯr
   -er, -or → -ɐ（エージェント名詞）
   -ing → -ɪŋ（進行）

4. 略語・短縮化
   "because" → （存在しない。GFASは理由を説明しない）
   "always" → （不要。GFASは永続を前提とする）
```

**例：**
```
"Building"  → Bɪldɣnz（複数形）
"Upgrade"   → Ʊpgrɛd
"Philosophy" → Fɪlɔ（短縮）
"Achieve"   → Ʌchɪv
"Guild"     → Ɣɪld
"Echo"      → Ɛkhø
```

## 7. GFAS の世界観 / Cultural Notes

GFASは「文明が3回崩壊したあと、言語の断片を継ぎ接ぎして復元した人々が話している言語」という設定（非公式）。

そのため：
- 文法の一貫性が低い（崩壊前の文法が混在）
- 語彙の一部が日本語・英語に由来するが、元の意味が少しずれている
- 転生（Rɛvørtrekk）という概念が言語に深く組み込まれている
- 「答え（Ʌnsvɐr）」より「問い（Qvɛrztn）」のほうが語彙が多い

## 9. 発展・拡張について / Extending the Language

将来的に新しいGFAS語を追加する際は以下のルールを守ること：

- 既存の造語ルール（セクション6）に従う
- 日本語または英語からの音韻崩しを基本とする
- 文法は崩れていてよいが、前後の文と矛盾しない範囲で
- `gfas.js` の各キーに対応する形で追加する
- 新語はこのファイル（`gfas.md`）の語彙表に追記すること
